# Support

## Getting help

1. Read the [README](README.md) and package documentation.
2. Search existing [issues](https://github.com/codenaline/payment/issues) and [discussions](https://github.com/codenaline/payment/discussions).
3. Ask usage questions in GitHub Discussions.
4. Open an issue for a reproducible bug or focused feature request.

Include the `payment` version or commit, Go version, provider, whether sandbox mode is enabled, and a minimal example. Never publish merchant IDs, API keys, full callback URLs, authorities, customer details, or other sensitive data.

Provider outages, account approval, settlement disputes, and production credential problems must be handled with the payment provider. Community support is best effort and does not include application-specific routing, persistence, retry policy, reconciliation, or business rules.

Report suspected vulnerabilities privately according to [SECURITY.md](SECURITY.md).
